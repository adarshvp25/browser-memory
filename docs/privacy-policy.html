Privacy Policy — Browser Memory

Browser Memory · Version 0.1.0

Last updated: August 31, 2026

1.Introduction

Browser Memory is a Chrome extension that lets you save webpages, selected text from webpages, and your own notes, so you can find them again later by searching. This page explains what information Browser Memory stores, how it is used, and what it does not do.

This policy describes the extension as it is actually implemented in version 0.1.0. If a future version changes how data is handled, this policy will be updated to match.

2.Information Stored by Browser Memory

Browser Memory stores only the information you explicitly choose to save, specifically:

  • Page title — the title of a webpage you save
  • Page URL — the address of a webpage you save
  • Selected webpage text — text you highlight and save using the right-click "Save selection to Browser Memory" menu action
  • Notes — plain text you type yourself and attach to a saved page
  • Creation and update timestamps — when an item was saved or last edited
  • Extension-generated item IDs — an internal identifier the extension assigns to each saved item so it can be found, edited, or deleted

Browser Memory does not ask you to create an account, and does not collect your name, email address, or any other personal identifier as part of its saving functionality.

3.How Information Is Used

The information listed above is used solely to provide the extension's core functionality:

  • Displaying your saved items in the extension popup
  • Letting you search your saved items by title, URL, selected text, or note
  • Letting you reopen the original webpage for a saved item
  • Letting you add, edit, or remove a note on a saved page
  • Preventing duplicate entries when you save a page you've already saved

Browser Memory only reads a webpage's title and URL at the moment you take an explicit save action — clicking "Save current page," using the keyboard shortcut, or using the right-click save-selection menu item. It does not run in the background or observe pages you have not chosen to save.

4.Where Information Is Stored

All saved information is stored locally on your device using Chrome's built-in chrome.storage.local API. There is no external database, server, or backend that Browser Memory sends this data to.

Your saved items stay on the device and Chrome profile where you saved them. Browser Memory does not currently sync data between devices or browsers. Uninstalling the extension, or clearing the extension's storage, removes this data from that device.

Browser Memory does not encrypt this stored data beyond whatever protections Chrome itself applies to extension storage on your device, and does not maintain any backup or retention schedule for it — how long it persists depends entirely on your own use of the extension (for example, deleting items or uninstalling it).

5.Information We Do Not Collect

Browser Memory does not:

  • Transmit saved pages, URLs, selected text, notes, or any other saved data to our servers or to any third party
  • Make network requests (no fetch, XHR, WebSocket, or similar background requests) to send or retrieve your data
  • Collect or monitor your general browsing history — it only accesses the current tab's title/URL, or selected text, at the moment you trigger a save action
  • Use analytics, telemetry, tracking pixels, advertising SDKs, or any other tracking or profiling technology
  • Load or execute any remote JavaScript, CSS, or WebAssembly — all code that runs is packaged with the extension
  • Require or use a user account, login, or authentication of any kind

6.Feedback Form / Google Forms

The extension popup includes an optional "Feedback" link. Clicking it opens a Google Forms page in a normal new browser tab, entirely outside the extension.

  • Opening the form is voluntary — Browser Memory does not open it automatically or on any schedule.
  • Browser Memory does not automatically fill in or submit any of your saved items, notes, or other extension data to the form.
  • Any information you choose to type into that form is submitted directly to Google Forms by you, and is subject to Google's own privacy practices, not Browser Memory's. We do not control what Google does with form submissions.

7.Data Deletion

You can delete any individual saved item directly from the extension popup using its Delete control. Deleting an item removes it from chrome.storage.local immediately.

To remove all data at once, you can uninstall the extension from Chrome, which removes its local storage on that device.

8.Permissions

Browser Memory requests the minimum Chrome extension permissions needed for its features:

Permission Why it is needed
storage Save and retrieve your items locally via chrome.storage.local.
activeTab Read the current tab's title and URL only when you trigger a save action (button click, keyboard shortcut, or context-menu item).
contextMenus Add the "Save selection to Browser Memory" option to Chrome's right-click menu.

Browser Memory does not request broad host permissions, general tabs access, browsing history access, or any permission beyond what is listed above.

9.Changes to This Privacy Policy

If Browser Memory's data handling changes in a future version — for example, if a sync feature were added — this policy will be updated to accurately describe that change before or alongside the update, and the "Last updated" date above will be revised.
